# java-calculator-precourse

### ✅ 구현 기능 목록

> 입력한 문자열에서 숫자를 추출하여 더하는 계산기
>
- [ ]  사용자 문자열 입력받기
- [ ]  기본적으로 , 또는 : 을 구분자로 지정
- [ ]  커스텀 구분자 지정 가능 //(구분자) → ex. //; 라고 하면 ;을 구분자로 지정
- [ ]  구분자는 무조건 1개의 문자만 가능하게 함 → ex. //뒤에 여러개의 문자가 나왔다면 각각 한 char이 구분자가 됨
- [ ]  커스텀 구분자 지정 시 구분자 지정 후 줄바꿈하고 계산할 문자열 전달 → ex. //;\n1;2;3
- [ ]  숫자 검증 : 양수가 아닌 수가 있는지 검증
- [ ]  숫자 검증 : 양의 정수 및 양의 소수도 가능하도록 함
- [ ]  사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시키고 애플리케이션 종료
- [ ]  결과값 계산 : 결과값이 소수일 경우 두번째 자리에서 반올림한 값을 출력함
- [ ]  계산값 출력
